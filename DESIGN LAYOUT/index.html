1. FLEXBOX TRICK (Images ko side-by-side lagana)

  • Maine kya kiya: Jab mujhe do images ko ek doosre ke bagal mein (side-by-side) set karna tha, toh maine unhe ek parent container div mein dala aur CSS mein display: flex; ka use kiya.
  • Mera logic: Isse mujhe purane zamane ke gande float ya inline-block hacks nahi use karne pade. Maine gap property se dono ke beech space diya aur images ki width: 45%; rakh kar layout ko ekdum responsive aur safe bana diya.

    • 2. POSITION STICKY (Navbar ko upar chipkana)

  • Maine kya kiya: Maine apne multicolor navigation bar par position: sticky; top: 0; apply kiya.
  • Mera logic: Isse mera navbar pehle toh normal content ki tarah behave karta hai, lekin jaise hi main page ko niche scroll karti hoon aur navbar screen ke sabse upar (top: 0) pahunchta hai, wo wahi par freeze ho jata hai. Baaki ka poora content uske peeche se smoothly nikalta rehta hai. Maine z-index: 100; bhi lagaya taaki navbar hamesha baaki content ke upar chamakta rahe.

    • 3. POSITION FIXED (Logo ko corner par float karwana)

  • Maine kya kiya: Ek floating logo ya button ko screen ke right-side bottom corner par hamesha ke liye chipkane ke liye maine position: fixed; ka use kiya.
  • Mera logic: sticky ke ulti, fixed element ko page ke baaki content se koi matlab nahi hota, wo seedha laptop ya mobile ki visible screen (viewport) par lock ho jata hai. Maine use bottom: 20px; aur right: 20px; ka offset diya, jisse main chahe jitna bhi lamba scroll karoon, mera logo apni jagah se ek inch bhi nahi hilta aur ekdum professional "floating" look deta hai.
